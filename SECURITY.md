# Security

clued runs Claude Code on your machine and passes your messages to it. It makes no network calls of its own, and it keeps its state in `~/.clued/`.

## Reporting a problem

Please don't open a public issue for a security problem. Report it privately instead: on this repository's **Security** tab, choose **Report a vulnerability**. Say what you found, how to reproduce it, and what it lets someone do. You'll get an answer within a few days.

Problems in Claude Code itself go to Anthropic: see https://www.anthropic.com/responsible-disclosure-policy.
